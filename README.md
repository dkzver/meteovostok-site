# МетеоВосток — лендинг кондиционеров

Статический одностраничник для продажи кондиционеров: чёрно-белая база, белый текст, один акцент — розовый `#FF2E88`.

## Запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```powershell
cd D:\www\minus-climate
D:\tools\php83\php.exe -S 127.0.0.1:8021 -t .
```

Затем открыть http://127.0.0.1:8021/

Либо двойной клик по `start.bat`.

## Структура

```
minus-climate/
├── index.html
├── start.bat
├── css/
│   ├── fonts.css        локальные @font-face

    ├── fonts/           Unbounded, IBM Plex Sans, IBM Plex Mono (woff2)
```

## Технические детали

- Без фреймворков и сборки: HTML + CSS + vanilla JS.
- Шрифты локальные (Unbounded, IBM Plex Sans, IBM Plex Mono), внешних CDN нет.
- Все изображения — SVG, поэтому страница остаётся лёгкой и резкой на любом экране.
- Адаптив: 1920 / 1440 / 1024 / 768 / 390 px, проверено отсутствие горизонтального скролла.
- Доступность: alt у изображений, aria-expanded у бургера, aria-pressed у кнопок, focus-visible, skip-link, поддержка `prefers-reduced-motion`.
- Контраст: основной текст 19:1, вторичный 7.4:1, мелкие подписи 5:1, розовый на чёрном 5.6:1, чёрный на розовом 6.5:1.

## Важно

Это демонстрационный дизайн-проект: названия товаров, цены, акции, адреса и телефоны приведены как пример. Перед публикацией замените их на реальные данные и добавьте настоящую карту.
